# Метки triage

Роли навыков соответствуют значениям поля `Status:` в файлах задач.

| Роль навыка | Значение в трекере | Значение роли |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Требуется первичная оценка |
| `needs-info` | `needs-info` | Ожидается дополнительная информация |
| `ready-for-agent` | `ready-for-agent` | Задача описана и готова к выполнению агентом |
| `ready-for-human` | `ready-for-human` | Требуется выполнение человеком |
| `wontfix` | `wontfix` | Задача отклонена |

Когда навык просит применить роль triage, используй соответствующее
значение из таблицы. Для изменения словаря редактируй столбец
«Значение в трекере».
