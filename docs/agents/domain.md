# Доменные документы

Проект использует single-context: один словарь терминов
и общие архитектурные решения.

## Перед исследованием проекта

- Прочитай `GLOSSARY.md` в корне репозитория, если он существует.
- Прочитай документы из `docs/adr/`, относящиеся к области задачи.
- Если документов пока нет, продолжай работу без предупреждений
  и предложений создать их заранее. Навык `domain-modeling` создаёт
  их по мере согласования терминов и решений.

## Структура

- `GLOSSARY.md` — термины проекта.
- `docs/adr/NNNN-<slug>.md` — архитектурные решения.

## Терминология

Используй термины из словаря в задачах, предложениях изменений,
гипотезах и названиях тестов. Если нужного понятия нет, проверь,
соответствует ли оно языку проекта; реальный пробел отметь
для `domain-modeling`.

## Противоречия решениям

Если предложение противоречит существующему ADR, явно укажи
номер решения, суть противоречия и причину его пересмотра.
