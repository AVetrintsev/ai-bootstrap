# Инструменты проекта

При добавлении GitHub-проекта платформа устанавливает ripgrep, ast-grep, Serena и
CodeGraphContext в его постоянную песочницу. Версии закреплены в `release.env`.
Serena и CodeGraphContext используют разные Python-окружения, поскольку их
закреплённые версии требуют несовместимые версии MCP SDK.

Состояние **Готов** появляется после первого индекса CodeGraphContext. Ошибка
оставляет проект и рабочую копию на месте; **Повторить добавление** завершает
подготовку в прежней песочнице. Для существующего проекта установщик обновляет
инструменты вместе с подключением Canvas. Отдельная команда восстановления:

```sh
sudo ai-sandbox tools-setup gh-ID
```

Codex и Qwen Code используют одинаковые инструменты из Canvas и терминала.
Рабочая копия — `/workspace/repo`. В терминале доступны `rg` и `ast-grep`.
Настройки Qwen находятся в `/root/.qwen/settings.json`; установщик сохраняет
прочие ключи этого файла. Codex получает управляемые настройки для подписки и
API-профиля на доверенной стороне, а MCP-процессы запускает через исполнитель
внутри контейнера. Секреты ChatGPT в песочницу не передаются.

Граф FalkorDB Lite хранится в `/root/.local/share/ai-codegraph` внутри постоянного контейнера.
Один процесс CodeGraphContext обслуживает клиентов через локальный Unix-сокет
`/run/ai-codegraph.sock`: одновременные вызовы из терминала и Canvas не открывают
базу из разных процессов. Новых сетевых портов нет. Служба
`ai-bootstrap-project-tools.service` пользователя проекта запускается при загрузке,
восстанавливает индекс и наблюдение за файлами. Изменения, сделанные во время
остановки службы, сверяются при запуске. Удалять рабочую копию или базу для
повторной настройки не требуется.

Диск новых песочниц — 8 ГиБ. При подключении инструментов существующий диск
расширяется с 4 до 8 ГиБ без пересоздания контейнера. Установленные пакеты,
история, конфигурация и файлы сохраняются.

Проверки на целевой VM:

```sh
sudo python3 tests/accept_project_tools.py gh-ID
```

Сценарий для TypeScript-проектов проверяет команды, два одновременных MCP-клиента, поиск символов Serena,
добавление, изменение и удаление символов в графе. Использует временный файл в
рабочей копии и удаляет его в конце.

Основание: [MCP Codex](https://learn.chatgpt.com/docs/extend/mcp?surface=cli),
[MCP Qwen](https://qwenlm.github.io/qwen-code-docs/en/users/features/mcp/),
[Serena](https://oraios.github.io/serena/02-usage/030_clients.html),
[CodeGraphContext](https://codegraphcontext.github.io/reference/cli/).
