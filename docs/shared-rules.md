# Общие правила

На главной странице портала откройте **«Общие правила»**. Владелец может
добавить правило, изменить его текст или раскрыть действие удаления.
Правила управляются отдельно от общей памяти; агентам не нужно предлагать
их через Graphiti. Нужны действующая сессия владельца и защищённая форма.

Каждое правило содержит до 4000 символов. В списке может быть до 50 правил,
суммарно до 16000 символов. Переносы строк и специальные символы сохраняются;
HTML отображается как текст. Если правило уже изменили в другой вкладке,
портал не перезаписывает новую версию и сохраняет введённый текст на странице
ошибки для копирования.

Codex и Qwen получают текущий список при начале нового сеанса в Canvas или
терминале. После редактирования или удаления создайте новый разговор либо
перезапустите терминальный агент. История ранее открытого разговора сохраняется
и может содержать прежний текст. Codex также обновляет инструкции при загрузке
сохранённого разговора; это не удаляет прежние сообщения из его истории.

## Хранение и граница доступа

SQLite хранится на VM в `/var/lib/ai-rules/rules.sqlite3`. Каталог принадлежит
`ai-portal`, не монтируется в песочницы и сохраняется при повторной установке.
Инициализация создаёт только отсутствующую таблицу. Сохранение транзакционное;
изменение и удаление проверяют версию показанного владельцу правила.

Доверенная служба Codex читает базу в режиме `ro`. При создании и загрузке
разговора она передаёт текст через `developerInstructions` app-server.
Клиент песочницы не может заменить этот параметр. Qwen перед запуском читает
правила через `GET /v1/platform/rules` существующего шлюза моделей с ключом
своего проекта и передаёт их через `--append-system-prompt`. Это поддерживает
также автономные песочницы без Codex. Чтение не расходует квоту запросов модели
и не запускает модель. Методов изменения правил в шлюзе нет.
При недоступности правил запуск задания останавливается с ошибкой.

Секреты модели и авторизации не добавляются к правилам. Файл правил доступен
для чтения службам VM: его содержимое предназначено всем проектам.

Контракты: [Codex app-server](https://learn.chatgpt.com/docs/app-server),
[дополнительные инструкции Qwen](https://qwenlm.github.io/qwen-code-docs/en/users/features/headless/).

## Проверки на VM

Интеграционные проверки используют временную базу, настоящие HTTP/Unix-интерфейсы
и тестовый внешний процесс Codex. Проверяются действия владельца, CSRF,
устаревшие формы, лимиты Unicode, продление сессии, запрет записи из шлюза,
правила для двух проектов и отказ при недоступности базы.

```sh
python3 -m unittest discover -s tests -p test_shared_rules.py -v
sudo BROWSER_PYTHON tests/accept_shared_rules.py gh-FIRST gh-SECOND CHROMIUM ./install.sh
```

Приёмка запускается вне активной работы в выбранных проектах. Она добавляет
временное правило через браузер и проверяет 24 завершённых ответа настоящих
агентов: два проекта, Codex/Qwen, терминал/Canvas, добавление/изменение/удаление.
Терминальные команды выполняются в `/workspace/repo`. После изменения правила
сценарий перезапускает службы и повторяет установку с текущим защищённым YAML.
Аргумент установщика обязателен для подтверждения сохранности после повторной
установки; без него проверяется только перезапуск служб.

Временные правило, сессия владельца и разговоры Canvas удаляются, в том числе
при неуспехе отдельных шагов. Остальные правила и разговоры сохраняются.
