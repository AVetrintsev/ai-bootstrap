# Инструкции для агентов

Общайся с пользователем на русском языке.

## Git workflow

1. Веди каждую задачу в отдельной ветке от актуальной `main` основного репозитория. Если настроен форк, используй ветку в форке. Прямые коммиты и push в `main` запрещены.
2. Оформляй каждую существенную правку отдельным коммитом и сразу отправляй его на сервер в ветку задачи. Публикуй промежуточные коммиты по ходу работы, включая существенные обновления задач и комментариев к ним.
3. Как только задача выполнена полностью и обязательные проверки пройдены, слей ветку через pull request в `main` основного репозитория. Считай задачу завершённой после подтверждения слияния на сервере.

## Agent skills

### Issue tracker

Задачи и спецификации ведём в Markdown в `.scratch/<feature>/`.
Перед чтением, созданием или обновлением задач прочитай `docs/agents/issue-tracker.md`.

### Triage labels

Используем пять стандартных меток triage в поле `Status:`.
Перед классификацией задач прочитай `docs/agents/triage-labels.md`.

### Domain docs

Используем single-context: корневой `GLOSSARY.md` и `docs/adr/`.
Перед исследованием проекта прочитай `docs/agents/domain.md`.
