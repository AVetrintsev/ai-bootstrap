# 04: Активировать владельца и зарегистрировать браузер

**Выполнение:** завершено 2026-11-09.

**What to build:** Владелец активирует портал через одноразовую ссылку и TOTP, а затем при необходимости регистрирует новый браузер. Защищённые страницы, API и потоки доступны после проверки сессии.

**Blocked by:** 02 — Запустить локальный HTTP без домена.

- [x] При первом запуске установщик выдаёт случайную ссылку с адресом выбранного режима. По ней владелец получает QR для Google Authenticator и подтверждает первый шестизначный код. Ссылка закрывается при успехе или через 24 часа. Ссылки и секреты отсутствуют в журналах, секрет TOTP защищён при хранении.
- [x] Через скрытый URL браузер регистрируется шестизначным TOTP с шагом 30 секунд. Nginx ограничивает частоту, а сервис допускает три ошибки за скользящий час по IP и учётной записи. Общий лимит блокирует новые регистрации со всех IP и сохраняет действующие сессии.
- [x] Сессии, счётчики и использованные коды хранятся транзакционно в локальной SQLite с кешем страниц в памяти. После перезапуска лимиты и сессии сохраняются. При одновременной подаче одного кода создаётся только одна сессия.
- [x] При успехе браузер получает случайный токен в cookie с `HttpOnly` и `SameSite=Strict` и переходит на `/`. Сервер хранит хеш токена. Проверка в `local-http` проходит через SSH-туннель.
- [x] Запросы к защищённым маршрутам страниц, API и потоков без действительной сессии получают `404`. До подключения Canvas это проверяется на тестовом потоке за тем же правилом Nginx.

## Comments

### 2026-11-09 — проверка на VM AI

- Установщик дважды успешно отработал в `local-http` с действующим профилем mihomo. Конфигурация Nginx и службы systemd прошли проверку. Nginx слушал только `127.0.0.1:8080`.
- Через SSH-туннель установленный Nginx вернул `404` без сессии для главной страницы, API и тестового потока. На той же VM изолированный экземпляр с временной SQLite показал QR, прошёл активацию по TOTP и проверку cookie, открытие страницы, API и получение обоих событий потока через Nginx и туннель. Рабочий портал оставлен для активации владельцем.
- Из двух одновременных запросов с одним TOTP один зарегистрировал браузер. Перезапуск службы сохранил обе действующие сессии и счётчик ошибок. Третья ошибка блокировала регистрацию, действующие сессии продолжили работать. Ограничение частоты Nginx вернуло `429` на серию запросов.
- Полный набор из 10 тестов прошёл на Ubuntu. В числе проверок срок ссылки в 24 часа, её одноразовость, истечение скользящего лимита и атрибут `Secure` в HTTPS-режиме приложения. Публичный HTTPS разворачивается в задаче № 16.
