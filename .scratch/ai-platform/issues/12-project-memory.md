# 12: Подключить память проекта

**What to build:** Codex и Qwen используют общую для их проекта долговременную память через Graphiti. Записи сохраняются между запусками.

**Blocked by:** 10 — Подключить Codex по подписке в портале.

- [ ] Запись, добавленная одним агентом через MCP, доступна другому агенту в том же проекте. Проверены вызовы из Canvas и терминала.
- [ ] Сервис ограничивает чтение и запись границей проекта. Попытки получить память соседнего проекта отклоняются, в том числе при подмене идентификатора проекта в запросе.
- [ ] Записи Graphiti с FalkorDB сохраняются после перезапуска и повторной установки. Из песочницы нельзя получить служебные учётные данные Graphiti или подключиться напрямую к FalkorDB.
