**What to build:** После добавления проекта владелец нажимает «Открыть» в портале и выполняет задачу с Qwen Code в Canvas. Платформа автоматически подключает песочницу через Agent Server с ACP.

**Blocked by:** 07 — Подключить GitHub и добавить приватный проект, 08 — Запустить Qwen Code через шлюз моделей.

- [ ] На закреплённой версии Canvas проверен поддерживаемый способ автоматического подключения. Адрес и ключ Agent Server передаются платформой. Владелец открывает проект из портала без ручного ввода этих данных.
