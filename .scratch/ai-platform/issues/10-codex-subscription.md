# 10: Подключить Codex по подписке в портале

**What to build:** Владелец подтверждает вход в ChatGPT в браузере при настройке и использует Codex по подписке из Canvas и терминала проекта.

**Blocked by:** нет — приёмка №03 выполнена в этой ветке, №09 ранее слита в `main`.

- [x] После подтверждения в браузере Codex по умолчанию работает по подписке ChatGPT. В Canvas и терминале он выполняет задачу с инструментом в той же песочнице, что и Qwen Code. Оба агента используют одинаковые права Git проекта.
- [x] Реализована проверенная схема с авторизованным процессом вне песочницы. Из песочницы нельзя прочитать учётные данные ChatGPT. При отключении исполнителя операция завершается явной ошибкой.
- [x] Портал различает необходимость повторного входа и исчерпание лимита подписки. Переключение на настроенный платный API-профиль происходит только по явному действию владельца.

### 2026-11-12 — блокировка целевой VM и граница интеграции

- Hyper-V сообщает `0x800705AA`: невозможно выделить 8192 МБ. VM остаётся `Off`; на хосте доступно около 4,3 ГБ физической памяти. Настройки памяти VM не менялись. Владельцу предложено освободить память либо разрешить запуск с 4 ГБ.
- Текущий Agent Server 1.62.0 запускается внутри контейнера. Поэтому обычный запуск в нём авторизованного Codex не выполняет требование изоляции ChatGPT. Требуется отдельная доверенная служба и ограниченный интерфейс проекта, без передачи полного API app-server песочнице.
- В исходниках Codex 0.166.0 подтверждены `include_local = false` и транспорт исполнителя через `program`/`args`. Кандидат: закрытый Unix-сокет и запуск `codex exec-server --listen stdio` внутри существующего контейнера. Это результат чтения исходников, а не пройденная приёмка. [Формат среды](https://github.com/openai/codex/blob/rust-v0.166.0/codex-rs/exec-server/src/environment_toml.rs), [протокол исполнителя](https://github.com/openai/codex/blob/rust-v0.166.0/codex-rs/exec-server/README.md).
- Официальная документация описывает вход через `chatgptDeviceCode`, отдельные сведения о лимитах и работу по API-ключу. Совместимость этих методов с закреплённым бинарником нужно подтвердить его схемой на VM. [Вход](https://learn.chatgpt.com/docs/auth#login-on-headless-devices), [app-server](https://learn.chatgpt.com/docs/app-server).
- Реализация служб и изменение действующей платформы ещё не выполнялись. Ни отдельные тесты, ни полный набор, ни сквозная проверка Canvas/терминала не запускались. Слияния нет. Для продолжения нужен доступ к VM; подтверждение браузерного входа потребуется при настройке подписки.
