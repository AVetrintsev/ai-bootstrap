# 07: Подключить GitHub и добавить приватный проект

**What to build:** Владелец один раз подключает GitHub App в портале, выбирает разрешённый приватный репозиторий и получает рабочую копию в постоянной песочнице.

**Blocked by:** 04 — Активировать владельца и зарегистрировать браузер, 06 — Запустить постоянную песочницу проекта.

- [ ] Из портала в `local-http` владелец подключает GitHub App. Если используется возврат браузера, он проходит через SSH-туннель. В форме «Добавить проект» видны только репозитории, разрешённые приложению.
- [ ] После однократного подключения можно добавить два разрешённых приватных репозитория. Для каждого создаётся постоянная песочница, и клонирование можно проверить из её терминала.
- [ ] Ключ приложения хранится вне песочниц. Git использует автоматически обновляемые короткоживущие токены только для репозитория своего проекта. Проверено, что токен одного проекта не даёт доступ к другому. `push` следует разрешениям приложения и правилам веток.
- [ ] После сбоя повторное добавление того же проекта использует прежнее окружение и завершает недостающие шаги без дубликатов. Удаление проекта доступно отдельным явным действием.
