# Штатная интеграция OpenHands

## Согласованный результат

Основание: решения владельца от 16 ноября 2026 года по пунктам аудита.

- Удалить собственный переводчик Codex app-server → ACP, использовать готовый закреплённый codex-acp. Сохранить авторизацию вне песочниц и исполнение внутри проекта; закрыть пути доступа к ключам через конфигурацию, MCP, файловые операции и чужие сессии.
- Использовать поддерживаемые возможности подключения Canvas, профилей и разговоров вместо изменения внутренних browser storage contracts, где это позволяет закреплённый upstream.
- Сохранить выполненный в PR #23 откат DOM-скриптов и приватного расширения Agent Server. Дать выбор модели и reasoning штатными настройками/профилями; допустимы понятные варианты модели с уровнями, если они поддержаны контрактом агента. Не выдумывать несуществующие model IDs.
- Использовать штатные worktree OpenHands с корректным исполнением, индексами, восстановлением и изоляцией соседних задач.
- Убрать лишние зависимости начала разговора от дополнительного инструментария; MCP должен корректно работать из Canvas и терминала.
- Удалить управление общими правилами, их доставку агентам и зависимость запуска от базы правил.
- Сохранить память проекта и общую память через MCP, включая действующую изоляцию и подтверждение публикации.
- Удалить собственные квоты Qwen, счётчики расходов и принудительные ограничения длины ответа. Бюджеты задаёт владелец у провайдера. Транспорт, скрывающий provider credentials от песочницы, не должен вводить финансовую политику.
- Сохранить изоляцию контейнеров, сеть, GitHub credentials и авторизацию портала.

## Проверки

Все тесты выполняются только на целевой Linux VM. До применения проверяются удаление правил/квот, штатный ACP, модели/effort, новая и возобновлённая сессии, MCP и два worktree. До завершения обязательны проверки недоступности ключей/соседнего проекта и отказа при потере исполнителя, а также сквозной Canvas/терминальный путь. Не считать исходниковый анализ заменой этим проверкам.
